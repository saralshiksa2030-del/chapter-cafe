# Licences and credits

Every file that is not code we wrote ourselves must be listed here
(file name, where it came from, who made it, and its licence).
WHY: licences change, and this file proves we used each file legally.

## Rule for this project
Only bundle files that are **CC0** (public domain dedication). CC0 means
anyone may use the file for any purpose without asking or giving credit.
Re-check the licence on the source page on the day you download.

## Where to find CC0 loops (free)
- Freesound: https://freesound.org/ . Search for a sound, then in the
  filters choose License > "Creative Commons 0".
  (I believe a free account is needed to download. Check the site.)
- Do NOT use files marked "Attribution" or "NonCommercial" unless you add
  the credit here and are sure the licence allows your use.

## What to look for
- Length 30 to 60 seconds, ideally described as a "loop" or "seamless".
- Calm, no sudden loud moments, no speech you can understand.
- Mono is fine and uses half the memory of stereo.
- Edit and export with Audacity (free) or ffmpeg (free). Keep each file
  small (a few MB). Export as OGG (best for seamless loops) AND/OR MP3.
